# SDÜ Katılım Formu

Süleyman Demirel Üniversitesi'nde yaptığım stajda, bir üniversite etkinliği için geliştirdiğim ASP.NET Core MVC tabanlı bir katılım/kayıt formu. Uygulama canlıya alındı.

## Özellikler
- Form doğrulama (zorunlu alanlar, e-posta formatı, QR kod onayı)
- Entity Framework Core ile SQL Server veritabanına kayıt
- Bootstrap ile responsive arayüz

## Kullanılan Teknolojiler
C# · ASP.NET Core MVC · Entity Framework Core · SQL Server · Bootstrap
